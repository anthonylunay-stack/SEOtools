Taxonomie SeLoger Edito

Mapping des tags et des catégories du site éditorial, avec détection des doublons et des libellés proches qui se font concurrence.

Données d'exemple
Importer le flux JSON des tags et URLs

Collez le JSON ou déposez le fichier. Formats acceptés : un tableau d'objets {name, url, count, parent}, un objet {tags:[…], categories:[…]}, un dictionnaire {"libellé": "url"} ou une simple liste d'URLs. Le type est déduit de l'URL : /tags/… → tag, /rubrique/… ou chemin de rubrique → catégorie. Les articles avec un champ tags sont agrégés.
