Formats acceptés

Un tableau d'objets {name, url, count, parent}, un objet {tags:[…], categories:[…]}, un dictionnaire {"libellé": "url"} ou une simple liste d'URLs. Le type est déduit de l'URL : /tags/… → tag, /rubrique/… ou chemin de rubrique → catégorie. Les articles avec un champ tags sont agrégés. Les sites sont repérés par le domaine des URLs, un champ site ou une clé de domaine ({"edito.seloger.com": {…}}) : un bouton par site apparaît en haut à gauche.
